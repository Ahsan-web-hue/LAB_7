# LAB_7
Serial UART DMA STM32 Programming with STM32F103C8T6 Blue Pill C++

This repository provides a complete implementation of Serial UART communication using Direct Memory Access (DMA) on the STM32F103C8T6 Blue Pill. The project is written in C++ using the STM32 HAL Library and configured with STM32CubeMX.
**Features**
UART Transmit using DMA
UART Receive using DMA
STM32 HAL-based C++ implementation
STM32CubeMX project configuration
Interrupt and callback handling
Circular buffer implementation
Reusable UART DMA class
Well-commented source code
Example application
Suitable for learning and embedded systems projects
Technologies
STM32F103C8T6 Blue Pill
STM32CubeMX
STM32CubeIDE
STM32 HAL Library
C++
DMA
UART
ARM Cortex-M3

This project serves as a complete reference for implementing UART DMA communication on STM32 microcontrollers while following object-oriented programming practices in C++.
